# Humoco WoT Agents & Skills

Dieses Verzeichnis enthält spezialisierte Agenten und Fähigkeiten zur Unterstützung der Entwicklung des Web of Trust (WoT).

## Verfügbare Agenten

### [Humoco WoT Architect](wot-architect/plugin.json)
Ein spezialisierter Assistent für architektonische Entscheidungen, Protokoll-Design und Sybil-Schutz-Mechanismen.

- **Wissensbasis:** ADRs, Spezifikations-Dokumente und das [WoT-Architektur Skill](wot-architect/skills/wot-architecture/SKILL.md).
- **Zweck:** Validierung von Feature-Entwürfen gegenüber den Kernprinzipien (Privacy-First, Offline-First, Sybil-Resistenz).

## Nutzung
Um den Agenten zu aktivieren, informiere dich über seine Fähigkeiten in der `SKILL.md`. Er kann zur Bewertung von PRs, Design-Entwürfen und Implementierungs-Fragen herangezogen werden.
